# dados processados

esta pasta contém três GeoJSON derivados de uma consulta real ao OpenStreetMap:

- `vias.geojson` — 334 feições;
- `areas_verdes.geojson` — 14 feições;
- `equipamentos_candidatos.geojson` — 25 feições.

os arquivos usam WGS 84 (`EPSG:4326`) conforme o formato GeoJSON e foram validados por `scripts/validar_geojson.py`.
